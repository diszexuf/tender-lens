# Tender Lens — структура презентации

Тезисы для слайдов защиты. Числа — из реальных прогонов; перед защитой обновите их по свежему расчёту.

## 1. Проблема

- Обоснование НМЦК методом сопоставимых рыночных цен (ст. 22 44-ФЗ, приказ Минэкономразвития № 567) — ручной поиск цен, сверка характеристик, расчёт однородности.
- Ошибки: несопоставимые товары в выборке, цены без НДС рядом с ценами с НДС, старые контрактные цены, непроверяемые источники.

## 2. Путь от текста до цены

- Вход — свободный текст закупки; выход — НМЦК с отчётом.
- Схема пайплайна: разбор → сбор → дедупликация → top-K → характеристики → сравнение кодом → нормализация → выбросы и CV → цена.
- Демо UC-01 (кабель): 22 предложения → 4 цены контрактов ЕИС, CV 17,45 %, 114,11 ₽/м.

## 3. Прозрачность отчёта

- У каждого предложения — решение и причина (19 кодов исключения), шаги нормализации с коэффициентами, снапшот страницы с SHA-256.
- XLSX: среднее, σ, CV — формулы Excel по строкам выборки; дают ту же цену, что UI.
- Версии расчёта: настройки, модель, версии промптов; ручные решения с комментарием переходят в следующие версии.

## 4. Качество сопоставления

- LLM только извлекает значения; сравнивает код. Ответ модели проверяется по тексту предложения.
- Эталон: 193 размеченных решения по 9 закупкам; ошибки решений — 3,8 % (гибридный режим) против 17,9 % в исходной версии.
- Неоднородная выборка (UC-02, скрепки: CV 62,8 %) — цена не выдаётся, система показывает группы цен.

## 5. Устойчивость

- Сбой источника не прерывает расчёт; статусы `timeout`, `structure_changed`, `blocked`, `circuit_open`.
- Circuit breaker по источнику, кэш ответов 24 ч с исходным `fetched_at`, восстановление после рестарта воркера.
- Новые источники — из UI по JSON Schema адаптера, с кнопкой «Проверить источник».

## 6. Ограничения

- Локальная модель `qwen3:4b` на 6 ГБ VRAM: позиция — 1–4 минуты; на CPU в несколько раз дольше.
- ГИСП и справочник КТРУ не подключены.
- Таблица ИПЦ при первом запуске — годовые значения, разнесённые по месяцам; помесячные нужно внести.
- Эталонный набор пока 9 закупок; услуги не размечены.

## 7. План развития

- Внешние LLM через тот же интерфейс провайдера — только с маскированием персональных данных (модуль готов и покрыт тестами).
- ЭТП и маркетплейсы как `html`-источники, ГИСП, КТРУ.
- Загрузка файлов ТЗ, авторизация, экспорт конфигурации источников.
